## 版本说明

这是 **Windows 域名证书有效性诊断工具 (CertificateChecker)** 的首个候选版本（`v0.1.0-rc.1`）。专为 Windows Server 生产环境设计，提供单文件绿色免安装桌面端及 CLI 模式，用于快速排查 IIS、Windows 服务及 Schannel TLS 证书的不被接受原因并给出可执行的修复建议。

## 主要内容

- **免安装绿色单文件**：基于 Rust 与 `eframe/egui` 构建，零外部运行时依赖（无需 WebView2 或 VC++ 运行库），纯 Windows GUI 子系统无黑色控制台弹窗。
- **双来源证书加载**：
  - 支持枚举与筛选 Windows 本地存储区（`LocalMachine` / `CurrentUser` 下的 `My`、`WebHosting`、`Root`、`CA`），自动探查是否关联私钥。
  - 支持读取本地证书文件：PEM（`.crt`/`.pem`）、DER（`.cer`）与加密 PKCS#12（`.pfx`/`.p12`）。
- **全方位诊断与顾问建议**：
  - 时间有效性检查（已过期、未生效、30 天/7 天临期预警）。
  - 严格遵循 RFC 6125 的域名 SAN 匹配与单级/多级通配符误用识别。
  - 调用 Windows 原生 CryptoAPI (`CertVerifyCertificateChainPolicy` / `CERT_CHAIN_POLICY_SSL`) 真实模拟系统 Schannel 信任链策略，捕获 `CERT_E_UNTRUSTEDROOT (0x800B0109)` 等错误并生成一键 `certutil` 修复命令。
  - 算法安全基线与服务端 `Server Authentication` EKU 约束校验。
- **简约桌面终端界面**：顶部配置与操作区固定全宽对齐，诊断日志以深色终端输出流呈现且滚动条仅在日志区生效，支持一键复制报告与导出 JSON。
- **自动化验证与发布流水线**：内置端到端证书场景集成测试与基于版本标签的 GitHub Actions CI/CD 自动打包发布流程。

> 这是首个候选版本。下载后请使用 `SHA256SUMS` 校验文件完整性；若在内网服务器上向系统导入私有根证书，请以管理员身份执行建议中的 `certutil` 命令。
